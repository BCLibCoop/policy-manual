Accessibility Metadata
----------------------

Accessibility metadata can be included in MARC records in the 008, 341, and 532 fields. This metadata is used by Evergreen for:

* format icons
* search filters (coming October 2026)
* accessibility features tab (coming October 2026)

Accessible Libraries has a resource that libaries may find useful when working with the 341 and 532 fields. See
https://accessiblelibraries.ca/resources/accessibility-metadata-for-library-staff/[Creating and editing accessibility 
metadata MARC tags for library staff].

Format Icons
~~~~~~~~~~~~

Sitka's Evergreen uses information entered into the form of the item position in the 008 field to 
determine if icons for braille or large print should be displayed for a record.

The Braille format icon will display when the Leader position 06 = a and the 008 position 23 = f.

image:images/guidelines-accessibility-metadata-1a.png[scaledwidth="75%"]

The Large Print format icon will display when the Leader
position 06 = a, Leader position 07 = a, c, d, or m and the 008 position 23 = d.

image:images/guidelines-accessibility-metadata-1b.png[scaledwidth="75%"]



Search Filters
~~~~~~~~~~~~~~

Formats
^^^^^^^

The Formats search filter includes Braille and Books (large print) as options. 

image:images/guidelines-accessibility-metadata-2a.png[scaledwidth="75%"]

When Braille is selected as a filter, records applicable to the search term used will be returned if the Leader
position 06 = a and the 008 position 23 = f.

When Books (large print) is selected as a filter, records applicable to the search term used will be returned if the Leader
position 06 = a, Leader position 07 = a, c, d, or m and the 008 position 23 = d.


Accessibility Features
^^^^^^^^^^^^^^^^^^^^^^

[NOTE]
======
The Accessibility Features search filter shown here is not available until October 5 2026. 
======

The Accessibility Features search filter will enable patrons to search for items with desired accessibility features.

image:images/guidelines-accessibility-metadata-2.png[scaledwidth="75%"]

When a search filter option is chosen, records applicable to the search term used will be returned the 341 field in
the MARC record contains the corresponding value. A record with the 341 fields pictured here would be returned as a result
if the Visual, Auditory, Closed captions, and/or Audio description filter options were chosen.

Accessibility Features Tab
~~~~~~~~~~~~~~~~~~~~~~~~~~

[NOTE]
======
The Accessibility Features tab shown here is not available until October 5 2026. 
======

When viewing a record in the public catalogue patrons will now see an Accessibility Features tab. 

The text hightlighted in gray comes from the 341 field. The rest of the text comes from the 532 field.

image:images/guidelines-accessibility-metadata-4.png[scaledwidth="75%"]

The 341 fields pictured here result in the text highlighted in grey displaying in the above Accessibility Features tab example.

image:images/guidelines-accessibility-metadata-3.png[scaledwidth="75%"]
