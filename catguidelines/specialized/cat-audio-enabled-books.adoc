Audio-Enabled Books
~~~~~~~~~~~~~~~~~~~


Audio-enabled books are physical books that include an audio player permanently 
attached to the book. Examples of audio-enabled books are Wonderbooks and 
VOX Books.

When cataloguing audio-enabled books cataloguers should follow standard practices for cataloguing books, with
the exceptions of the following specified paramenters:

* Leader position 06 (Type) = a OR t
* Leader position 07 (Bib Level) = a, c, d, or m
* 006 position 06 (Form) = no value
* 008 position 23 (Form) = no value
* 020 (ISBN) $a = Used for the ISBN only if the ISBN is unique to the item
* 020 (ISBN) $z = Used for the ISBN if it the same ISBN belonging to the standard book
* 250 (Edition) = $aWonderbook OR $aVOX audio-enabled book
* 336 (Content Type) = $aspoken word$bspw$2rdacontent. OR 337 (Media Type) = $aaudio$bs$2rdamedia.
* 336 (Content Type) is NOT $astill image$bsti$2rdacontent. 


[CAUTION]
=========
It is very important that all 020 fields in the record are coded correctly. Incorrectly coded 020 fields may lead 
to audio-enabled book records being incorrectly merged with records for standard books and audiobooks.
=========

When these parameters are met a record will display in the staff and public catalogues with both the _Book_ and 
_Preloaded Audio_ icons.
